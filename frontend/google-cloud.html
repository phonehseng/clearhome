The website, the AI that answers questions, the map, and how each release ships. Here is exactly how we use Google Cloud, and how we get the most out of it on a small budget.

What Each Service Does

And what we do to push it further than the defaults.

Compute

Cloud Run

Hosts the whole website and its API as one container.

  • Close to youRuns in us-east4, the Google region closest to Northern Virginia.
  • Costs stay lowShuts down when nobody is visiting and never runs more than two copies.
  • Photos load fastListing photos are stored inside the app, so pages never wait on a landlord’s website.
  • Instant answersCommon questions are answered when the server starts, so the resources page responds right away.
  • Data stays safeThe live site is read-only. Data changes are reviewed on our computers first and shipped as code.
GPU

Cloud Run GPUs

Our own NVIDIA L4 graphics card runs Gemma 4 26B (through Ollama), just for Clear House.

  • Quick repliesHidden “thinking” is turned off, so answers start in seconds instead of after a minute.
  • PrivateIt refuses public calls. The website signs each request with its own Google identity.
  • Pay only when usedIt shuts down when idle and costs about $1 an hour while awake. During judging, one copy stays on so the first answer is fast.
  • Ready before you askThe GPU wakes up as soon as the chat scrolls into view, before you finish typing.
  • Never breaksIf the GPU is asleep or slow, the chat switches to the Gemini API after 20 seconds.
AI

Gemini API

Runs Gemma 4 (gemma-4-26b-a4b-it) and Gemini with Google Search.

  • Understands youGemma turns your message into search filters, then writes the answer using only checked listings, shown as it types.
  • Finds new placesGemini with Google Search looks for listings we don’t have yet. Only places that appear in the search results are kept, and the map marks them “not checked”.
  • Removes stale listingsGemma rereads listing pages and hides ones that are no longer offered. It can hide listings, never add them.
  • Protects your infoSocial Security and account numbers are removed before any text is sent.
Maps

Google Maps Platform

Three Google Maps tools: Maps JavaScript, Places API and Routes API.

  • The mapMaps JavaScript draws the map with a pin for every checked home.
  • Places nearbyPlaces API finds the place you name (an employer, a hospital, a school), plus the supermarkets, pharmacies and transit stops near a home.
  • Real travel timesRoutes API gives real drive and transit times from the closest homes, and true walking times to the store.
  • Keys kept apartThe server and the browser use separate keys, so the server key never reaches a web page.
Security

Secret Manager

Holds the Gemini key and both Maps keys.

  • Never in the codeKeys are not in the code, the repository or the app image.
  • Easy to changeSwapping a key means adding a new version and redeploying, with no code change.
Delivery

Cloud Build and Artifact Registry

Turn our code into running containers.

  • Fixes go live fastEvery deploy builds a fresh container from our Dockerfile, so a pushed fix is live in minutes.
  • Room for the big AI imageThe 17 GB Gemma GPU image is built on a larger Cloud Build machine and stored in Artifact Registry next to the site.

Full Power, Kept in Check

Using a GPU and live AI on a hackathon budget means building in limits from day one.

Pay only while in use

The website scales to zero and is capped at two copies. The GPU runs at most one copy and can scale to zero.

One switch to stop GPU costs

Removing one setting sends every chat back to the Gemini API, with no code change.

Nothing public that shouldn’t be

The GPU is private, keys live in Secret Manager, and the hosted site can’t change its own data.
