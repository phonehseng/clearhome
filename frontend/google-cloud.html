What each service does

And what we do to push it further than the defaults.

Compute

Cloud Run

Hosts the whole website and its API as one container.

  • Runs in us-east4, the region closest to Northern Virginia.
  • Scales to zero when nobody is visiting, and is capped at two instances so costs stay predictable.
  • Listing photos are baked into the image, so pages never wait on a landlord’s website.
  • Example questions are answered when the server starts, so the resources page responds instantly.
  • The hosted copy is read-only: data changes are reviewed locally and shipped as code.
GPU

Cloud Run GPUs

Our own NVIDIA L4 runs Gemma 4 26B (through Ollama) just for Clear House.

  • Hidden “thinking” is turned off, so answers start in seconds instead of after a minute.
  • Private: it refuses public calls. The website signs each request with its own Google identity.
  • It can scale to zero and costs about $1 an hour while awake. During judging we keep one copy warm so the first answer is fast.
  • The chat wakes the GPU as soon as it scrolls into view, before you finish typing.
  • If the GPU is asleep or slow, the chat switches to the Gemini API after 20 seconds, so it never breaks.
AI

Gemini API

Runs Gemma 4 (gemma-4-26b-a4b-it) and Gemini with Google Search.

  • Gemma turns your message into filters, then writes the answer using only checked listings, streamed as it types.
  • Gemini with Google Search grounding looks for listings we don’t have yet. Only places that appear in the search results are kept, and the map marks them “not checked”.
  • Gemma rereads listing pages and hides ones that are no longer offered. It can hide listings, never add them.
  • SSNs and account numbers are removed before any text is sent.
Maps

Google Maps Platform

Maps JavaScript, Places API and Routes API.

  • Maps JavaScript draws the map with a pin for every checked home.
  • Places API finds the place you name (an employer, a hospital, a school), plus the supermarkets, pharmacies and transit stops near a home.
  • Routes API gives real drive and transit times from the closest homes, and true walking times to the store.
  • Separate server and browser keys, so the server key never reaches a web page.
Security

Secret Manager

Holds the Gemini key and both Maps keys.

  • Keys are never in the code, the repository or the container image.
  • Rotating a key means adding a new secret version and redeploying, with no code change.
Delivery

Cloud Build and Artifact Registry

Turn our code into running containers.

  • Every deploy builds a fresh container from our Dockerfile in Cloud Build, so a pushed fix is live in minutes.
  • The 17 GB Gemma GPU image is built on a larger Cloud Build machine and stored in Artifact Registry next to the site.

Full power, kept in check

Using a GPU and live AI on a hackathon budget means building in limits from day one.

Pay only while in use

The website scales to zero and is capped at two copies. The GPU runs at most one copy and can scale to zero.

One switch to stop GPU costs

Removing one setting sends every chat back to the Gemini API, with no code change.

Nothing public that shouldn’t be

The GPU is private, keys live in Secret Manager, and the hosted site can’t change its own data.
