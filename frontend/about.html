    Built with Google Cloud

    AI

    Gemma 4 26B

    Writes every chat answer.

    AI

    Gemma 4 26B

    Turns your message into filters, then writes the answer using only checked listings, streamed as it types. It also rereads listing pages and hides ones that are gone.

    GPU

    Gemma on Cloud Run

    Our own L4 GPU: answers in ~3 s.

    GPU

    Gemma on Cloud Run

    Gemma 4 runs on our private Cloud Run service with an NVIDIA L4 GPU. Thinking is off so replies start fast; if the GPU is asleep, the Gemini API answers instead.

    Search

    Gemini API

    Finds new listings on the web.

    Search

    Gemini API

    Searches the web with Google Search grounding for listings we don’t have yet. Only places in the search results are kept, and the map marks them “not checked”.

    Maps

    Maps JavaScript

    The map, pins and Street View.

    Maps

    Maps JavaScript

    Draws the map in the app with a pin for every checked home, so you can see where a place is before you call.

    Maps

    Places API

    Finds “near my office”.

    Maps

    Places API

    Finds the place you name (an employer, a hospital, a school) and the supermarkets, pharmacies and transit stops near a home.

    Maps

    Routes API

    Real commute times.

    Maps

    Routes API

    Drive and transit times from the closest homes to your place, and true walking times to the store. Real routes, not straight lines.

    Cloud

    Cloud Run

    Hosts the site and the GPU.

    Cloud

    Cloud Run

    Hosts the site in Northern Virginia (us-east4). Keys live in Secret Manager, and at most two copies run, so costs stay small.

    Cloud

    Cloud Build

    Ships every release.

    Cloud

    Cloud Build

    Every deploy builds a fresh container from our Dockerfile, so a pushed fix is live in minutes.
