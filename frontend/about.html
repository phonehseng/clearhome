    The problem

    Finding a safe, affordable home shouldn't be this hard.

    Many renters spend more than 30% of their income on housing. When money is tight, every wrong step costs more.

    Help is scattered

    Shelters, assistance programs and affordable listings live on dozens of different sites.

    Rules are confusing

    Income limits, closed waitlists and program names make it hard to know what you can actually apply for.

    Location matters

    A cheap place an hour from work or school isn't really affordable once you add the commute.

    What Clear House does

    Three tools. One clear next step.

    Find housing help

    Describe your situation in your own words. We match you to shelters, rental assistance and affordable housing from a list our team checked by hand. If it's urgent, shelters come first.

    Try it

    Ask Gemma, live

    Ask in your own words and watch the answer stream in, using only our checked resources. Say "near my office at…" and get the closest homes with drive and transit times.

    Try it

    See it on a map

    Every reviewed home is a pin on Google Maps, with Street View to check the building. Find homes within walking distance of a grocery store, pharmacy or bus stop.

    Built with Google

    Gemma 4, Google Maps and Google Cloud, working together.

    Every answer is grounded in our hand-checked list. Here is what each Google technology does in Clear House.

    AI model

    Gemma 4 26B

    gemma-4-26b-a4b-it, Google’s open model, writes the chat answers. It only uses the checked records we hand it, streams its answer word by word, and every reply says which model answered.

    AI model, self-hosted

    Gemma 4 on a Cloud Run GPU

    The same Gemma 4 26B (gemma4:26b) runs on our own NVIDIA L4 GPU on Cloud Run with reasoning turned off, so answers start in seconds. If it’s asleep, the app falls back to the Gemini API.

    Gemini API

    Gemini API + Google Search grounding

    Calls Gemma 4 from the server, and powers the live web search on the map: Gemma searches Google for new affordable listings, shown in orange until our team checks them.

    Maps

    Maps JavaScript API

    The listings map: a house pin for every reviewed home, county outlines, Northern Virginia and Blacksburg tabs, Street View to see a building, and a map that follows the chat and your filters.

    Maps

    Places API (New)

    Finds the place you mean when you ask for homes “near my office” or “near Inova Fairfax Hospital”, and the grocery stores, pharmacies and bus stops near each home.

    Maps

    Routes API

    Real drive, transit and walking times from each home to your office, school or a nearby grocery store, plus the walking route drawn on the map.

    Cloud

    Cloud Run

    Hosts the website and the Gemma GPU service. Both scale to zero when nobody’s using them, so the project only costs money while people use it.

    Cloud

    Cloud Build + Artifact Registry

    Builds every release of the site and the 17 GB Gemma image from our GitHub code, and stores them for Cloud Run.

    Open source

    Every line of Clear House is on GitHub.

    The data, the Gemma prompts, the map and the tests are all public. Read it, run it, or improve it.

    Our promise

    Built to be careful with you.

    • We only recommend places from our hand-verified list. The AI is not allowed to make up addresses or phone numbers.
    • SSNs and account numbers are stripped from your documents on our server before any AI sees them.
    • No account needed, and we don't store what you type.
    • Answers are guidance, not legal advice. We point you to real people, like 211 and tenant legal aid, for decisions.

    Ready when you are.

    Start with a few words about what you need. You don't need all the answers.
